## 📌 Proje Hakkında

**ADA APPS**, bağımsız olarak geliştirilen Progressive Web Apps (PWA), masaüstü güvenlik araçları ve tarayıcı eklentilerini tek bir çatı altında toplayan kişisel bir **uygulama dağıtım vitrini ve ürün stüdyosu**dur.

Apple App Store ve Google Play gibi kapalı ekosistemlerin %30'a varan komisyonlarını, keyfi onay süreçlerini ve kullanıcı verisi sömürüsünü reddederek; **doğrudan web üzerinden (Direct Distribution)** çalışan, hafif, zanaatkar dijital ürünleri kullanıcılara sunar.

---

## 🏛️ Stüdyo Manifestosu & 4 Temel İlke

ADA APPS çatısı altındaki tüm projeler şu 4 sarsılmaz ilkeye göre inşa edilir:

1. **🛡️ Sıfır Veri Sömürüsü:** Veri madenciliği, gizli izleyici pikselleri veya kişisel bilgileri reklamcılara satma pratiği kesinlikle bulunmaz. Yerel öncelikli (Local-First) ve uçtan uca şifreli mimari esastır.
2. **⚡ PWA ve Doğrudan Dağıtım:** Aracı mağaza tekelleri olmadan, tek tıkla telefona, tablete veya masaüstüne ana ekran uygulaması olarak yükleme özgürlüğü.
3. **🌿 Dikkat Saygısı:** Dopamin tuzakları, sonsuz kaydırma veya zorlama bildirimler yok. Kullanıcının işini zarifçe çözüp gerçek hayatına dönmesini hedefler.
4. **🛠️ Zanaatkar Geliştiricilik:** Milyon dolarlık şişkin yazılımlar yerine; tek bir problemi yüksek hız ve estetikle çözen hafif, odaklı araçlar.

## ✨ Vitrin Öne Çıkan Özellikleri

- **🎨 ADA / APPS Marka Kimliği:** İki satırlı modern tipografik tasarım, squircle formunda gradyan rozet ve mikro-optik harf aralığı düzenlemeleri.
- **📱 İnteraktif Canlı Simülatörler (`LiveDemoDrawer`):** Her uygulama için gerçek zamanlı çalışan mini arayüz simülasyonları (örneğin GuitarFriends akor transpozesi, LessToken token budayıcısı, Evdeki Hesap bütçe paneli).
- **📲 QR Kod ile Mobil Kurulum (`QRCodeModal`):** Masaüstünden incelerken telefon kamerasıyla okutup saniyeler içinde PWA olarak yükleme imkanı.
- **🛠️ Geliştirici Yönetim Paneli (`CreatorStudioModal`):**
  - Yeni uygulama ekleme, düzenleme ve yayından kaldırma,
  - Statü değiştirme (Canlı, Beta, Geliştirilmekte, Prototip),
  - Tek tıkla JSON formatında dışa aktarma / içe aktarma ve sıfırlama,
  - `localStorage` tabanlı kalıcı ve göç destekli (Local-First) veri saklama.
- **🧭 Zengin Filtreleme & Arama:** Platform (PWA, Masaüstü, Eklenti, Canlı) ve kategori bazlı hızlı arama ve filtreleme.
- **💡 Neden PWA? Rehberi (`WhyPwaSection`):** Geleneksel App Store modeli ile PWA dağıtım modelinin karşılaştırmalı analizi.

## 🚀 Başlarken & Kurulum

Projeyi yerel geliştirme ortamınızda çalıştırmak için:

### Gereksinimler
- **Node.js**: v18.0 veya üzeri
- **npm** ya da **yarn** / **pnpm**

### 1. Depoyu Klonlayın
```bash
git clone https://github.com/kullanici/adaapps.git
cd adaapps
```

### 2. Bağımlılıkları Yükleyin
```bash
npm install
```

### 3. Geliştirme Sunucusunu Başlatın
```bash
npm run dev
```
Sunucu başladığında tarayıcınızda `http://localhost:3000` adresine gidin.

### 4. Üretim (Production) Derlemesi
```bash
npm run build
```
Derlenen optimize edilmiş statik dosyalar `dist/` klasöründe oluşturulur.

### 5. Tip Kontrolü & Linter
```bash
npm run lint
```

## ➕ Yeni Bir Uygulama Nasıl Eklenir?

Vitrine yeni bir proje eklemek için iki yöntem kullanabilirsiniz:

### Yöntem 1: Arayüz Üzerinden (Geliştirici Paneli)
1. Üst menüden veya alt bilgiden **"Geliştirici Paneli"** butonuna tıklayın.
2. Formu doldurun (İsim, Slogan, Kategori, Platform, Çözülen Problem, URL vb.).
3. **"Uygulamayı Vitrine Ekle"** butonuna basın. Projeniz anında yerel kataloğunuza eklenir.

### Yöntem 2: Kod Tabanı Üzerinden (Kalıcı Ekleme)
`src/data/appsData.ts` dosyasındaki `INITIAL_APPS` dizisine `AppItem` tipine uygun yeni bir nesne tanımlayın:
